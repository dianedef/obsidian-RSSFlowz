## What You Need to Do Next

### Create the First Release

To make this plugin installable via BRAT, you need to create a release with version tag `1.0.0`.

#### Option A: Use the Automated Script (Recommended)

```bash
# Switch to master/main branch and ensure it's up to date
git checkout master  # or main
git pull

# Run the helper script
./create-first-release.sh
```

The script will guide you through the process and automatically:
- Verify the build works
- Check all required files exist
- Create and push the tag 1.0.0
- Trigger the GitHub Actions workflow

#### Option B: Manual Process

```bash
# Switch to master/main branch
git checkout master  # or main
git pull

# Create and push the tag
git tag 1.0.0
git push origin 1.0.0
```

### What Happens After Pushing the Tag

The GitHub Actions workflow (`.github/workflows/release.yml`) will automatically:

1. **Install dependencies** with `npm ci`
2. **Build the plugin** with `npm run build` 
3. **Create a GitHub release** titled "1.0.0"
4. **Attach the required files**:
   - `main.js` (~354 KB)
   - `manifest.json`
   - `styles.css`

This usually takes 1-2 minutes.

### Verify the Release

1. Go to: https://github.com/dianedef/obsidian-RSSFlowz/releases
2. You should see a new release titled "1.0.0"
3. The release should have 3 files attached
4. Check the Actions tab if something went wrong

### Install with BRAT

Once the release exists, anyone can install the plugin via BRAT:

1. Install the [BRAT plugin](https://github.com/TfTHacker/obsidian42-brat) in Obsidian
2. Open Obsidian Settings → BRAT
3. Click "Add Beta plugin"
4. Enter: `dianedef/obsidian-RSSFlowz`
5. Enable the plugin in Settings → Community plugins

## Troubleshooting

### The workflow doesn't run
- Verify the tag was pushed: `git push origin 1.0.0`
- Check the Actions tab on GitHub for workflow status

### The release has no files
- Check the workflow logs in the Actions tab
- Verify `npm run build` works locally
- Ensure you pushed a proper semantic version tag (e.g., `1.0.0`, not `v1.0.0` or `up`)

### BRAT can't find the plugin
- Ensure at least one release with proper version tag exists (e.g., `1.0.0`)
- Verify the release is published (not draft)
- Check that all three files are attached to the release
- Ensure the repository is public
